# 最少配置：10 分钟把「我们一家」用起来

> 目标：只做**必须做**的几步，让全家能用上待办、动态、记录本、记账。
> **不需要**配邮件、企业微信、钉钉、飞书、AI —— 这些不配也能正常用，只是没有消息推送和截图识别。

---

## 你需要准备什么

| 项目 | 要求 |
| --- | --- |
| 一台常开的机器 | NAS、小主机、旧笔记本、云服务器都行；也可以先在自己电脑上试 |
| 运行环境 | Docker（推荐），或 Node.js **≥ 22.5** |
| 浏览器 | 手机或电脑的任意现代浏览器 |

不用买域名，不用开公网，不用装数据库。数据就是一个文件夹。

---

## 第 1 步：启动

### 方式 A：Docker（推荐）

```bash
mkdir -p data && sudo chown -R 1000:1000 data   # 首次必须先建目录并给对属主
cp .env.docker.example .env                      # 可选：改端口等
docker compose up -d
```

### 方式 B：Node 直跑（不用 Docker）

```bash
node server.js            # 默认端口 3455，数据落在 ./data
PORT=8080 node server.js  # 想换端口
```

不需要 `npm install` —— Node 22.5 自带 SQLite，项目零外部依赖。

### 方式 C：飞牛 NAS

应用中心 → 手动安装 → 选择 `familyhub-<版本>-fnos-<架构>.fpk`（x86 机型选 amd64，ARM 机型选 arm64）。

### 验证

浏览器打开 `http://机器IP:3455`，看到登录页就成功了。

---

## 第 2 步：注册管理员

登录页切到「注册新账号」，填用户名、昵称、密码。

**第一个注册的人自动成为管理员。** 同时系统会**自动关闭自助注册**（防止陌生人注册进来看见家里的内容），这是有意的安全默认值。

---

## 第 3 步：让家人加入

1. 用管理员账号进入 **我的 → 家庭设置和成员**。
2. 在「家庭设置」那一行点 **设置**，把「新成员自助注册」切到 **开放**，保存。
3. 家人在自己手机上打开同一个地址，注册账号。
4. 全部注册完，回到这里切回 **关闭**。

> 家人不需要是管理员；管理员权限只给第一个账号。要调整权限请在数据库层面处理，界面上不提供转让入口。

---

## 第 4 步：开始用

| 模块 | 怎么用 | 一句话 |
| --- | --- | --- |
| **待办** | 底部「待办」→ 右下角「待办」按钮 | 写标题、选日期和参与人；到点会提醒（需配推送，见下） |
| **动态** | 底部「动态」→ 发帖 | 文字 + 最多 9 张图或 3 段视频，家人可评论、可「一起写」 |
| **记录本** | 底部「记录本」→ 新建 | 存证件、账号、病史这类重要信息，可分类、可加附件、可上锁 |
| **记账** | 底部「记账」→ 输入框 | 直接说人话：`今天买菜 30 元`（本地解析，断网可用） |

四个模块的可见范围默认是「全家」，需要私密时在编辑里改成「仅自己」。

---

## 第 5 步：数据在哪、怎么备份

- 数据全在启动目录的 `data/` 里：`family.db`（数据库）+ `uploads/`（图片附件）。
- 备份两种做法：**整目录拷贝**，或管理员在 **我的 → 数据备份 → 导出备份** 下载一个文件。
- 恢复：同一页面选「恢复」，或把 `data/` 换回去再启动。

> 建议每周备份一次。SQLite 是单文件，拷贝前最好先停服务，或用页面里的导出。

## 这一版你**没有**配的东西

| 没配的 | 影响 |
| --- | --- |
| 发件邮箱（SMTP） | 没有邮件提醒；「忘记密码」不可用（需管理员重置） |
| 企业微信 / 钉钉 / 飞书 | 手机收不到推送；不能在企业微信里发消息记账 |
| AI 接口 | 记账只能手动输入，不能拍小票自动识别 |
| 反向代理 / HTTPS | 只能在内网用 `http://IP:3455` 访问（家里用通常够） |

## 常见问题

**Q：家里没有 NAS，能在电脑上先试吗？**
能。装 Node 22.5+，在该目录执行 `node server.js`，浏览器开 `http://127.0.0.1:3455`。电脑关机服务就停，数据仍在 `data/`。

**Q：注册入口不见了？**
管理员注册完会自动关闭。按第 3 步重新打开即可。

**Q：忘了管理员密码？**
没配发件邮箱时无法自助找回。处理办法见 [完全配置 · 账号与权限](02-完全配置.md#账号与权限)。

**Q：手机能像 App 一样装到桌面吗？**
能。iOS Safari「添加到主屏幕」、Android Chrome「安装应用」都支持，打开后没有地址栏。局域网 HTTP 也能装，只是不支持离线打开。
