## 一、配置全景

| 配什么 | 在哪 | 谁配 | 不配的后果 |
| --- | --- | --- | --- |
| 站点名称 / 时区 / 免登录 | 我的 → 家庭设置和成员 → 设置 | 管理员 | 用默认值，可用 |
| 注册开关 | 同上 | 管理员 | 家人无法自助加入 |
| 上传上限 | 同上 | 管理员 | 默认图片 10MB / 附件 20MB / 视频 50MB |
| 发件邮箱（SMTP） | 我的 → 推送渠道设置 → 邮件推送 | 管理员 | 无邮件提醒，忘记密码不可用 |
| 企业微信 | 我的 → 推送渠道设置 → 企业微信推送 | 管理员 | 微信里收不到、发不了 |
| 钉钉 / 飞书群机器人 | 我的 → 推送渠道设置 → 飞书 / 钉钉推送 | 管理员 | 群里收不到 |
| 个人接收方式 | 我的 → 消息推送设置 | 每位家人 | 只有管理员能收到 |
| AI 截图记账 | 我的 → AI 参数设置 | 管理员 | 只能手动录入 |
| 记账分类与预算 | 我的 → 记账分类与预算 | 每位家人 | 用内置分类，无预算预警 |
| 备份 | 我的 → 数据备份 | 管理员 | 数据只在硬盘上，坏了就没了 |

**一个关键区分**：推送分两层 —— **家庭级**（怎么发，管理员配）+ **个人级**（发给谁，每人自己配）。只配家庭级，其他家人依然收不到。

## 二、基础与安全

### 家庭设置 · 基础配置

| 字段 | 说明 | 建议 |
| --- | --- | --- |
| 站点名称 | 显示在标题、页脚、浏览器标签 | 改成自己家的名字，最多 20 字，「恢复默认」可还原 |
| 新成员自助注册 | 开放 / 关闭。首个管理员建成后自动关闭 | 加人时开放，加完立刻关闭 |
| 免登录有效期 | 1 小时 ~ 1 年 | 家用 1 天够；共用设备建议调短 |
| 时区 | 默认东八区 | 待办提醒、日报时间都按它算，改了要重新看提醒时间 |
| 图片 / 附件 / 视频上限 | 1–100 / 1–200 / 5–500 MB | 手机原图大，图片建议保持 10MB 以上 |

### 账号与权限

- **管理员**：第一个注册的账号。可以看全部成员参数、改家庭设置、配推送与 AI、导出备份。
- **成员**：能看到「全家」可见的内容；「指定成员可见」与「仅自己」按设置生效。
- **停用成员**（不是删除）：在我的 → 家庭设置和成员 → 点该成员右侧「停用」。停用后该账号立即不能登录、会话失效，**所有数据原样保留**；在同一个位置点「启用」即可恢复。被停用的人不会出现在待办参与人、指定可见、企微映射等任何选人列表里。
- **重置密码**：管理员在成员行点「重置密码」，设一个新密码告诉本人。
- **记录本访问密码**：管理员可为成员重置或清空记录本锁；成员自己也能在记录本里设自定义密码，登录密码可作备用钥匙。
- **忘记密码**：需要「账号绑了邮箱」+「家庭配了 SMTP」两个前提，登录页「忘记密码？」用邮箱验证码重置。缺任一前提请管理员重置。

### 内容可见性

每条待办 / 动态 / 记录都可以单独设可见范围：

| 范围 | 谁能看 |
| --- | --- |
| 全家 | 所有在用成员（默认） |
| 指定成员 | 勾选的人 + 作者自己 |
| 仅自己 | 只有作者 |

记录本另有一层整体锁：开启后进「记录本」页要先验密码。

## 三、推送（最值得花时间的一块）

### 四个通道怎么选

| 通道 | 投递到 | 需要公网地址 | 需要 IP 白名单 | 适合 |
| --- | --- | --- | --- | --- |
| **邮件** | 某人的邮箱 | 不需要 | 不需要 | 所有人；最稳的兜底 |
| **企业微信** | 某人的微信/企微 | 要收发双向才需要 | 需要（家宽动态 IP 可上代理） | 想在微信里收提醒、发消息记账 |
| **钉钉群** | 一个群 | 不需要 | 不需要 | 家庭群统一收提醒 |
| **飞书群** | 一个群 | 不需要 | 不需要 | 同上 |

详细步骤：[教程① 邮件](../tutorials/01-邮件推送配置-QQ邮箱.md)｜[教程② 企业微信](../tutorials/02-企业微信推送配置.md)｜[教程③ 企微代理](../tutorials/03-企业微信消息代理.md)｜[教程④ 钉钉与飞书](../tutorials/04-钉钉与飞书推送配置.md)

### 个人接收方式（每人一份）

我的 → 消息推送设置：

| 选项 | 行为 | 失败时 |
| --- | --- | --- |
| 智能（默认） | 绑了企业微信走企微，没绑走邮件 | 回落邮件 |
| 仅邮件 | 只发邮件 | 记日志 |
| 仅企业微信 | 只发企微 | 不回退 |
| 邮件 + 企业微信 | 两边都发 | 各自独立 |
| 飞书群 / 钉钉群 | 只发到群 | 不回退 |

同一页还能单独设「待办提醒」「内容通知」「记账推送」的开关与时间；不设就跟随家庭默认（待办当天 08:00、记账每天 21:00 日报 + 每月 1 号月报）。

### 内容通知

- **通知类型**：待办事项 / 图文动态 / 重点记录 / 评论，可分别开关。
- **免打扰时段**：例如 22:00–07:00。期间的变更会攒着，结束后合并成一封发出。
- **限流**：默认每分钟最多 20 封，防止一人反复编辑刷屏。
- **消息模板**：待办提醒 / 内容通知 / 记账推送三类共六条文案可自定义，支持变量，可一键恢复默认。

### 配完必做的一步

**我的 → 消息推送设置 → 推送日志**：每条投递都记着收件人、通道、成功或失败原因。收不到时先看这里，能立刻分清「根本没发」和「发了没收到」。

## 四、AI 截图记账

三项必填：

| 字段 | 千问（百炼）填法 |
| --- | --- |
| 接口地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| API Key | 控制台创建的 `sk-…`（只写不读） |
| 模型 ID | `qwen3-vl-flash`（必须支持图片输入） |

- **出厂默认指向 OpenAI**，国内网络下必须改地址，否则会超时 / 401。
- 任何提供 **OpenAI 兼容** `/chat/completions` 的平台都能用（DeepSeek、智谱、Gemini 兼容端点等）。
- **月度上限**默认 1000 次，到 95% 预警、用完停用，防止密钥被刷。
- 识别参数（超时 / 重试 / 压缩 / 分类策略 / 提示词）在「识别参数」里，网页上传和企业微信发图共用。
- 排查入口：**AI 参数设置 → 调用日志**，能看到每次调用的 token、耗时与原始错误。

完整步骤：[教程⑤ AI 接入](../tutorials/05-AI接入-千问.md)

## 五、记账

- **一句话记账**：本地解析，不联网、不耗额度。例：`今天买菜 30 元`、`昨天打车 26`、`这个月房租 3500`。
- **分类与预算**：我的 → 记账分类与预算。可改分类名、删分类（该分类下的记录归「通用」）、给分类设月度预算，超支时提醒。
- **快捷短语**：记账输入框上方的短语可自己编辑，每人一份。
- **统计**：个人 / 全家 × 日 / 月，支持筛选与日历两种看法，带分类排行。
- **导出**：CSV，UTF-8 带 BOM，Excel 直接打开不乱码。

## 六、部署进阶

### 挂在反向代理的子路径下

如果前面有 Nginx / 网关把应用挂在 `/familyhub` 这类前缀下，启动时加：

```bash
BASE_PATH=/familyhub node server.js
```

前端所有接口和静态资源会自动带前缀，**不用改代码、不用改数据库**。验证时可访问 `http://IP:3455/familyhub/`。

> 飞牛 fpk 已经默认 `BASE_PATH=/app/familyhub`（桌面图标走网关），不用再手动配。

### HTTPS

有域名时建议反代挂证书（Caddy / Nginx / 飞牛网关都行）。上了 HTTPS 之后：

- Cookie 自动加 `Secure`（需要 `TRUST_PROXY=1`，compose 默认已开）；
- PWA 才具备离线能力的前提条件。

### PWA（装到桌面）

- iOS Safari → 分享 → 添加到主屏幕；Android Chrome → 菜单 → 安装应用；桌面 Chrome/Edge → 地址栏右侧安装图标。
- 装完独立窗口打开、无地址栏。图标在 `public/icons/`，改设计后跑 `python scripts/make-icons-from-source.py` 重新生成。

### 飞牛 fpk

应用中心手动安装，架构要跟机型一致（x86 → amd64，ARM → arm64）。fpk 内已含 Node 运行时，不需要另装。

- **从飞牛桌面进入**：图标走飞牛统一网关（`/app/familyhub/`），和桌面同源、同端口。所以用 frp / 内网穿透时，**只要本来能打开飞牛桌面，这个应用就能打开**，不用再给 3455 单独开端口（旧版就是因为要求单独映射端口，外加 https 页面里嵌 http 子页面会被浏览器拦，才出现「点图标打不开」）。
- **浏览器直连**：`http://NAS的IP:3455` 依然可用，适合内网访问或排障（服务同时监听端口，前缀之外的请求照常处理）。
- **想换前缀或端口**：编辑 `/var/apps/familyhub/etc/app.env`（没有就新建），写 `BASE_PATH=/familyhub` 或 `PORT=3456`，然后在应用中心重启。注意桌面图标固定按 3455 转发，改了 PORT 只影响直连地址。

## 七、备份、恢复与升级

| 动作 | 做法 |
| --- | --- |
| 备份 | 我的 → 数据备份 → 导出备份（管理员），或停服务后整目录拷贝 `data/` |
| 恢复 | 同一页面选恢复并上传文件；或把 `data/` 换回去再启动 |
| 升级 | 换镜像 / 换 fpk 后重启；**数据库结构老库启动时自动补列**，不需要手工迁移 |
| 降级 | 先备份！旧版本可能不认识新列，回退前务必留好 `data/` 副本 |

`data/` 里就两样东西：`family.db`（含 WAL 文件）+ `uploads/`（图片与附件）。拷贝时整个目录一起拷。

## 九、故障速查

| 现象 | 先看这里 |
| --- | --- |
| 家人收不到提醒 | 推送日志 → 那人有没有填收件邮箱 / 推送方式选对没 |
| 企业微信报 60020 | 服务器出口 IP 不在「企业可信 IP」里；动态 IP 上 [教程③](../tutorials/03-企业微信消息代理.md) |
| 企业微信发消息没反应（但发测试消息正常） | 回调地址那一条方向没通，检查 URL / Token / AESKey |
| 钉钉 `sign not match` / 飞书 `19024` | 服务器时间不准，校准 NTP |
| 邮件 535 | 填的是登录密码，不是 16 位授权码 |
| AI 一直超时 | 接口地址还是出厂默认的 OpenAI，改成百炼兼容端点 |
| AI 分类总落到「其他」 | 「新分类的处理」选了「只用现有」 |
| 图片传不上去 | 家庭设置里的上传上限，或反代的 `client_max_body_size` |
| 打开是白屏 / 图标全丢 | 反代子路径没配 `BASE_PATH` |
